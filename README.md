# OptanAR Landing Page

Initial landing-page foundation for OptanAR.

## Structure

- `index.html` — main page
- `css/style.css` — visual identity and responsive styles
- `js/main.js` — interactive background
- `assets/images/` — place OptanAR images here
- `assets/videos/` — place pitch/demo videos here

## Technology

- Bootstrap 5 via CDN
- Custom CSS
- Native Canvas background animation
- Prepared for a future Three.js 3D background
